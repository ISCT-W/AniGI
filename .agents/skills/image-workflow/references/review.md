# 实际监修与准确版本

先定位候选、冻结参考和实际提交版本，再查看整体和必要局部。先不借助提示词描述实际看到的故事、动作和互动，再与导演目标比较；效果出现不证明预期动作成立。检查用户要求、叙事与视觉表达、身份/版本、行为、作画结构、生成瑕疵和修改回归。

只审核实际可见内容。合理遮挡或画外且不影响要求的部位记不适用，不编造缺陷；部分可见只核对可见关系。关键可见细节模糊、身份/互动不可读或用户要求展示的内容缺席仍阻断。不要把写实标准强加给约定风格。

优先查看高风险关系：对象归属、固定商品结构、手指与持握/承托面、动作方向、物体连接和特效来源。疑点用局部和原参考核对，保留全图上下文。模型自述“已修好”不能替代实际观察；既有明确错误不能被另一条无错误检查覆盖。

问题按稳定编号跨轮跟踪，写明位置、实际/预期表现、证据、影响、阻断或建议、具体修改和应保持内容。每次修改同时检查目标是否修复与其余区域是否退化。原因仅是可检验假设，不能从一次生成推断内部机制。

通过须完成必要检查，满足用户和参考约束及适用视觉目标，没有阻断和影响验收的关键未知。可保留非阻断建议。没有实际看图只能记未执行；多 Agent 一致或校验值相符不能证明质量。只有实际安排另一 Agent 复核才称独立审查。

每张候选独立登记，绑定准确图片、报告及参考版本。修改报告、变换图像或裁切后重新审核新版本，不能复用旧通过标记。最终图片仅通过交付入口复制到任务根 `final_output/`；视频首帧是中间产物，须另做首帧适用性审查，不能作为最终视频交付。

最后一次请求有图仍完整监修。耗尽后保留失败候选与问题，不能称“最佳候选”为通过成品。展示实际文件、Agent 结论、用户验收状态、次数与已知限制。
