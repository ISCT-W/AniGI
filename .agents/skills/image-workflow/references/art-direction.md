# 导演构图与修改设计

由自然语言目标形成一个可读、有情绪的故事瞬间。简单展示只需明确观看重点，不强加剧情；复杂场景可先比较少量文字分镜，不消耗生图次数。

1. 明确谁想做什么、谁回应或阻止、这个瞬间为何重要。静态图只选一个连贯动作阶段，不同时要求尚未挥动和已经命中。
2. 安排第一视觉重点、景别、机位、深度、人物相对位置及视线路径。镜头服务用户目的，合理遮挡、背侧面、近景和夸张透视均可；不为检查方便强求全身正脸。
3. 分别设计每人的意图、朝向、重心、动作线、视线、手和物体的接触。相似服装不能变成机械相同姿态；检查手是否占用、同一肢体是否承担冲突动作。
4. 按证据确定特效与身体/道具的关系、方向、形状、配色和层次。环境响应服务动作与情绪，不用强烈特效掩盖不可读的主体动作。
5. 检查交付尺寸下关键对象和固定细节是否可读。若用户要求展示的部分被遮挡或过小，调整方案；不能预先接受关键细节简化。

实际提交文字先描述连贯场景，再写逐人动作、参考职责、固定事实与允许变化、输出设置。泛用“电影感”“完美”等形容词不能替代可执行设计。相邻动作参考用于理解运动，只有单帧时不声称已证明完整轨迹。

修改时先判断根因所在：资料冲突先调整参考；局部错误可编辑；故事、构图或起始动作不成立则重做设计。记录缺陷与依据、原因假设、本轮变化、保留项和回归判据。历史候选可以比最新版更适合作底图，但仍携带已知缺陷；被用户禁止的图片不再输入。重生成继承基线和失败经验，不意味着重新开始额度。

视频首帧还需与第一秒状态相接，保留后续动作空间、手部可用性和可解释的视线方向。视频失败通常修正当前段计划并保持同一已审起点，不能默认重画首帧。
