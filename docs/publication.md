# 公开文件检查与导出

公开候选由根目录 `public-files.txt` 逐文件列出。每行一个相对路径，不支持目录、通配符、绝对路径或路径跳转。只有内容已经过人工审查的文件才加入清单；`.gitignore` 也应逐文件放行，不能先放行整个目录。

```sh
python scripts/public_release.py --root .
python scripts/public_release.py --root . --output .private/public-export
```

输出目录必须不存在。工具先读取清单、验证文件类型并扫描全部内容，通过后将检查过的原始字节写入新目录，再检查导出结果。它不加载环境配置、不访问外部资料源、不初始化 Git、不上传或推送文件。

本地可在 `.private/publication-rules.json` 提供额外禁止模式，或用 `--rules` 指定同样格式的私有文件。此规则文件不进入导出。格式为 `{"patterns": [{"category": "private_semantics", "regex": "本地禁止模式"}]}`；类别只允许小写字母和下划线，模式内容和匹配值都不会出现在诊断中。默认规则检查凭据格式、非示例邮箱、用户绝对路径、认证 URL、签名参数和 UUID 类资源标识；本地规则补充组织特有名词及私有功能表述。无本地规则时，工具明确报告仅执行通用检查。

扫描覆盖正文、注释、错误文字、测试、文档、技能及文件名。符号链接、二进制、受保护目录、真实媒体与运行类文件被直接拒绝；被清单引用的本地配置仍会拒绝，不因“已列入清单”而放行。诊断只显示位置和类别。不要把真实密钥作为扫描器测试输入，测试使用合成材料。

模式扫描不能识别全部隐私语义。导出前安排未参与实现的审查者，检查是否还描述了特定私有资料服务的能力、调用顺序、返回结构、内部机制或真实案例。人造示例应从零编写，不用真实响应改名字。检查真实 Git 跟踪、暂存内容和可达历史；忽略规则不能清理已跟踪内容或历史。

在新导出目录中运行离线测试和帮助入口，确认缺少本地配置也能运行。测试输出、压缩包、CI 日志和发布附件均遵守相同公开边界。零模式命中不等于绝对无泄漏；报告实际检查范围及尚未验证部分。实际发布只按用户另行要求执行。
