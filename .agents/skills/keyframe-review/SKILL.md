# 首帧监修

当前 Codex 在独立步骤执行。先读仓库根 [制作合同](../../../docs/workflows.md)，字段以当前工具帮助为准。切换导演/监修职责不等于另一个 Agent 独立复核。

1. 读取冻结标准、原始资料和导演设计，实际查看准确候选全图与必要局部。原始参考优先于生成图或导演解释；衣服发色相似不足以证明身份与画风一致。
2. 分别判断 `identity`、`style`、`product`、`contact`、`composition`、`motion_feasibility` 和每个严格保持项。无商品等不适用项说明依据，不伪造观察结果。
3. 接触沿手指—握柄/承托面—物体追踪，保持全图上下文。合理遮挡和透视可以通过，但关键关系不可读时保留未知，不能以缺少反例写通过。
4. 验证能否从首帧演出第一秒：意图、视线、空间、手部占用和动作阶段是否成立。漂亮静态海报不能自动成为可执行剧情起点。
5. 只有六类检查及严格项全部满足，且没有关键未知，才正式接受。明确错误拒绝，影响验收的具体疑点保持待核验。报告绑定准确候选、请求/设计、原始参考及通用图片审核版本；Markdown或手写通过标签不能代替工具记录。
6. 拒绝后向导演反馈位置、证据、保留项、修改建议和回归判据。可编辑、换合适历史底图或重做设计，继续同一六次额度；用户禁止的候选不可作输入。每次修改后重看全图并检查回归。
7. 首帧通过后，真实上传回执必须指向同一内容校验值，视频提交也必须引用该绑定。手写 URL、不同像素文件或通用图片通过不能绕过。通过首帧仍是中间产物，不进入任务根最终视频交付目录。

重开已通过首帧前解决在途请求并撤销相关下游。后续五秒片段默认沿用已通过前段真实末帧/末段，不每段另生成首帧。
