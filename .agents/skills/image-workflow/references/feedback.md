# 反馈留痕

用户反馈记录在对应任务 `feedback.md`，保存原话、时间和准确媒体/交付版本。用户原话、Codex 理解及已执行动作分别写；无法确定评论对象且影响修改时保持待澄清。用户无回复不能算接受；评论或问题本身也不授权再生成。

制作前与每轮监修前读取本任务适用反馈。若用户已有本地反馈规则，仅按其范围检索和应用；一次构图偏好不能自动升级为通用约束，其他对象案例不能变成当前角色事实。当前明确指令优先于历史偏好；事实冲突需回查原参考。

可复用规则使用包内 `rule.md` 模板，在用户已有私有规则目录保存来源、适用范围、状态、检查方法及例外，不编造没有收到的反馈或自动召回能力。没有用户要求时不额外建立规则平台；真实规则和索引不能进入公开导出。

验收单独记录 Agent 是否通过及用户待验收/接受/要求修改，绑定具体版本。用户否决后保留旧文件和意见，撤销其当前有效交付指向，新版本另存。重审改变结论时保留旧报告，不追改历史以制造“一直通过”的记录。
