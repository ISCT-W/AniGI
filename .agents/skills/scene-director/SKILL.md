# 逐秒导演

由当前 Codex 执行。先读仓库根 [制作合同](../../../docs/workflows.md)，逐秒结构见 [编排格式](references/second-by-second.md)。`video-workflow` 在首次计划、通过后接续和失败修订时使用本技能。

1. 分开用户要求、导演补充和未知资料。用户不懂镜头语言不构成阻塞；在意图内自主补充，保留角色/版本和固定造型严格项。
2. 明确情绪因果：谁注意到什么，为何行动，对方何时回应。不同人物的动机、视线和节奏应有区别，避免机械同步成为默认。
3. 先安排全片事件，再逐秒记录场景、镜头、每位主体的动作/注意力/情绪、因果与结束状态。每秒一行，不要求每秒切镜或新动作。持续和等待也写明；动作可以跨秒，保持准备—执行—反应关系。
4. 每五秒一个生成片段。后段初稿是条件性意图；前段通过后实际看末帧/末段，再修订后段起点、逐秒表和提示词。不能为了接续无意义冻结画面。
5. 检查占手、支撑、空间、动作方向、反应先后和五秒内事件密度。减少次要事件，不突破用户约束。镜头允许合理遮挡，不默认全员全身正面。
6. 提示词包含参考编号及职责、风格/空间、当前五秒行为和必要连续性约束。完整审核资料留在合同，不把所有细节硬塞进提示词。逐秒规划不保证生成器精确按秒执行；不编写本流程未要求的音频制作/监修内容。

首帧输出 `composition`、`starting_action`、`motion_feasibility`、`reference_roles`。第一秒应能从首帧状态继续，提前检查视线、移动空间和手部占用；随后由 `keyframe-review` 实际审查。导演的创作理由不能抵消保真错误。

失败修订写上一候选/片段、缺陷位置及依据、原因假设、保留项、针对性变化与回归检查。首帧可编辑、选合适历史底图或重做构图，沿用六次总额度；视频通常修正当前五秒提示词并使用相同已审起点，沿用每段五次额度。用户禁止复用的失败图不输入；失败素材不能成为正确性权威。若首帧修改，先使依赖下游失效并解决在途请求。
